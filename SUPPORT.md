# Support

For normal bugs and feature requests, use the GitHub issue templates.

Before reporting a problem:

1. Confirm that the required speech or translation model is installed.
2. Run the built-in microphone test and system check.
3. Try the latest LocalVoice release.
4. Include your Windows/Linux version, LocalVoice version, selected model and relevant settings.

Do not attach private recordings, transcriptions, encryption keys, PINs, personal paths or sensitive logs to a public issue.

Security vulnerabilities must be reported according to `SECURITY.md`.
