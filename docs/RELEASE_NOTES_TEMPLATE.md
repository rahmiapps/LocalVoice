# LocalVoice 2.1.1

LocalVoice is a private, local speech-to-text and translation application for Windows and Linux.

## Highlights

- Fully local speech recognition after model installation
- Hold-to-record and toggle recording modes
- Global configurable hotkeys
- Automatic language detection and local translation
- Direct text insertion into the active application
- Personal vocabulary, profiles and encrypted local history
- Six complete interface languages
- No account, advertising, subscription or paid API

## Download

### Windows

- `LocalVoice-Setup-Windows-x64.exe` — standard installer
- `LocalVoice-Windows-x64-Portable.zip` — portable package

### Linux

- `LocalVoice-Linux-x86_64.AppImage`
- `LocalVoice-Linux-amd64.deb`
- `LocalVoice-Linux-x64.tar.gz`

## Verification

Compare downloaded files with `SHA256SUMS.txt`.

## First start

1. Select the interface language.
2. Choose and test the microphone.
3. Install a speech model from the local model manager.
4. Configure the recording hotkey and mode.

## Notes

Speech-recognition speed depends on model size and hardware. Medium and Large models improve recognition on many systems but require more memory and processing power.
