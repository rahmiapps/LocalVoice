# Installation

## Windows

1. Download `LocalVoice-Setup-Windows-x64.exe` from GitHub Releases.
2. Start the installer.
3. Complete the installation wizard.
4. Select the application language on first launch.
5. Open the model manager and install a speech model.
6. Test the microphone and recording hotkey.

Unsigned community builds may trigger a Windows SmartScreen warning. Verify the SHA-256 checksum published with the release before running a downloaded installer.

## Linux

Use the package suitable for the distribution:

- AppImage for a portable desktop package
- DEB for Debian, Ubuntu, Linux Mint and related distributions
- TAR.GZ for a portable extracted installation

Global hotkeys and automatic text insertion can behave differently under X11 and Wayland. LocalVoice uses supported platform paths and safe clipboard fallback behavior where direct insertion is unavailable.
